# Visual Casebook · exemplos originais

Esta é uma galeria para **recuperação e crítica**, não um conjunto de layouts obrigatórios. Cada exemplo SVG é autoral, escalável e acompanhado de uma ficha com intent, ontology, use_when, avoid_when e decisões de codificação.

- Não copiar a composição sem adequar os objetos ao argumento.
- Exemplos marcados `anti` são intencionalmente ruins.
- Sem fotografias terceirizadas ou slides protegidos redistribuídos.
- Diagramas científicos são **esquemáticos e sem escala**; devem ser confrontados com a fonte antes de uso didático.
- Conteúdo numérico fora dos casos reportados explicitamente é marcado ilustrativo.

Veja [GOAL](../../goals/slide-quality-loop/GOAL.md) e [contrato semântico](../../docs/SEMANTIC_VISUALS.md). O catálogo visual em `catalog.jsonl` armazena os metadados.
